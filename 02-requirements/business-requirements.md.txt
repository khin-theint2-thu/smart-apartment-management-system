# Requirements: Smart Apartment Management System

Properties: **RungRuang Mansion** (A, B, C, D) and **Marisa Residence** (A, B, C)

## Business Rules

| ID | Rule |
|---|---|
| BR-01 | RungRuang rent per room: A 3,500, B 3,800, C 3,800, D 4,500 THB/month. |
| BR-02 | RungRuang deposit = 2 months' rent + 100 keycard fee. |
| BR-03 | Marisa B and C rent is 6,500/month. A 2-bedroom starts from 13,000. A 1-bedroom price is TBD. |
| BR-04 | Marisa deposit is 8,500 for all buildings. |
| BR-05 | Marisa A and B contracts are 6 months. Marisa C contracts are 12 months. |
| BR-06 | Contracts with any other term for Marisa are blocked. |

## Functional Requirements

| ID | Requirement |
|---|---|
| FR-01 | Manage multiple properties, buildings, room types and rent. |
| FR-02 | Manage tenant profiles and documents. |
| FR-03 | Create, renew and terminate contracts. |
| FR-04 | Calculate deposit automatically per BR-02 and BR-04. |
| FR-05 | Enforce contract term per BR-05 and BR-06. |
| FR-06 | Detect contracts nearing expiry daily. |
| FR-07 | Send contract expiry reminders at 90, 60, 30, 15 and 7 days, on expiry day and after. |
| FR-08 | Send reminders by LINE, SMS and in-app notification. |
| FR-09 | Support Auto, Approval and Manual send modes. |
| FR-10 | Stop reminders on renewal or termination, and never send duplicates. |
| FR-11 | Create repair tickets (tenant portal or manager entry) with photo and priority. |
| FR-12 | Assign tickets and require acknowledgement from owner or technician. |
| FR-13 | Remind and escalate unresolved tickets at 4, 24, 48 and 72 hours, then daily. |
| FR-14 | Notify tenants on every ticket status change. Close only after tenant confirmation. |
| FR-15 | Generate rent invoices and track payments and arrears. |
| FR-16 | Show dashboards and reports by property and building. |
| FR-17 | Restrict access by role and assigned property. |
| FR-18 | Keep an audit log and notification history. |

## Non-Functional Requirements

| ID | Requirement |
|---|---|
| NFR-01 | Daily reminder scan finishes within 5 minutes. |
| NFR-02 | Scheduler recovers from missed runs. |
| NFR-03 | Sensitive data is encrypted. |
| NFR-04 | Messages available in English and Thai. |
| NFR-05 | Failed notifications are retried, then logged and flagged. |
